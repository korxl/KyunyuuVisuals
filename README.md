# KyunyuuVisuals

Минималистичный визуальный клиент для **Minecraft 1.21.4** (Fabric). Тёмное стекло, плавные анимации,
размытие фона, аккуратный Click GUI и собственный HUD.

![loader](https://img.shields.io/badge/loader-Fabric-22D3EE)
![java](https://img.shields.io/badge/java-21-4ADE80)

## Возможности

### Click GUI (`RightShift`)
- Единая стеклянная панель в современном стиле: скруглённые углы, мягкие тени, тонкие бордеры.
- Размытие мира на фоне (`Menu blur`) + тёмный скрим и медленно плывущие акцентные глоу-пятна.
- Анимация открытия, плавные hover-подсветки, анимированные переключатели и слайдеры.
- Категории **Visuals / Hud / Client** с иконками и акцентным индикатором.
- Живой поиск по модулям.
- Инспектор настроек справа: навёл курсор на модуль — сразу видишь и правишь его опции.
- Типы настроек: переключатель, слайдер, режим (циклический), выбор оттенка (hue), бинд клавиши.
- Настройки клиента: размытие, анимации и их скорость, акцентный цвет, уведомления, тени текста.
- Кнопки «Open HUD editor» и «Save config».

### HUD
- **Watermark** — бренд с пульсирующей акцентной точкой.
- **FPS** — с цветовой индикацией (зелёный/жёлтый).
- **CPS** — отдельно ЛКМ и ПКМ.
- **Coords** — координаты + текущий биом.
- **Ping** — задержка с цветовой шкалой.
- **Keystrokes** — WASD + LMB/RMB с анимацией нажатия.
- **Armor** — 4 слота брони с полосками прочности.
- **Clock** — локальное время.
- **Memory** — занятая/выделенная память JVM.
- **HUD editor** — перетаскивание элементов мышью, ПКМ скрывает элемент.

### Модули
| Модуль | Категория | Описание |
| --- | --- | --- |
| Fullbright | Visuals | Осветляет лайтмапу, не трогая настройку гаммы |
| NoHurtCam | Visuals | Убирает наклон камеры при получении урона |
| NoBob | Visuals | Отключает покачивание камеры при ходьбе |
| CustomTime | Visuals | Клиентское время суток (Day/Noon/Sunset/Night/Midnight/Custom) |
| Zoom | Visuals | Плавный оптический зум на удержание клавиши (по умолчанию `C`) |

### Уведомления
При включении/выключении модуля справа сверху выезжает тост с акцентной полосой и прогресс-баром.

## Установка
1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft **1.21.4** и Java 21.
2. Положите [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.4 в папку `mods`.
3. Положите `kyunyuuvisuals-1.0.0.jar` в папку `mods`.
4. Запустите игру и нажмите **RightShift**.

> Мод полностью клиентский: он не нужен на сервере и не меняет игровую логику.

## Сборка из исходников
```bash
./gradlew build
# готовый jar: build/libs/kyunyuuvisuals-1.0.0.jar
```

## Конфиг
Настройки, позиции HUD и бинды сохраняются в `config/kyunyuuvisuals.json` и загружаются при старте.

## Структура
```
src/main/java/dev/kyunyuu/visuals
├── KyunyuuVisuals.java      точка входа
├── client/                  глобальные настройки клиента
├── config/                  JSON-конфиг
├── gui/                     ClickGuiScreen, HudEditorScreen
├── hud/                     HUD-рендер и уведомления
├── mixin/                   GameRenderer (NoHurtCam, Zoom), Lightmap (Fullbright)
├── module/                  система модулей и настроек
├── module/impl/             визуальные модули и HUD-элементы
├── render/                  Paint (AA-скругления, тени, глоу) и Theme
└── util/                    Anim и Easing
```
